# Gaussian 블러 비교 실험 (C, TEAM_CONTRACT §8.5)

> 교육용 실험이다. 공개 비식별 데이터(LIDC-IDRI)로 만든 결과이며, 진단 화질이나 임상 성능을 뜻하지 않는다.

## 요약

- **효과가 있었던 조건:** 고르게 퍼진 Gaussian 잡음. 대표 영상에서 PSNR이 24.8 → 31.2 dB(k=5)로 올랐고, LIDC 23장 평균으로는 k=9에서 +7.9 ± 3.2 dB였다. 균일 영역(flat ROI)의 표준편차는 20.3 → 13.6으로 잡음을 넣기 전 수준(13.7)까지 돌아왔다.
- **정보가 손실된 조건:** kernel·sigma가 커질수록 미세 구조가 사라진다. 잡음이 없는 원본에서 폐 혈관 ROI의 경계 세기가 k=5에서 66%, k=15에서 39%만 남았다. k=15(σ≈2.6)부터는 화면 기준 선명도가 54로 떨어져 `check_quality`(demo-v2, 기준 65)에서 **흐림 의심**으로 판정될 수준이다.
- **효과가 부족했던 조건:** 소금·후추(점) 잡음. Gaussian은 점을 주변으로 퍼뜨릴 뿐이라, PSNR을 Median 3(33.2 dB) 수준으로 올리지 못했다(최고 29.5 dB, k=15). 그때는 이미 경계 세기가 42%까지 떨어진다.
- **파라미터:** 흐림 정도를 실제로 정하는 것은 sigma다. k=15에 σ=1을 주면 k=5(자동 σ≈1.1)와 결과가 거의 같다(PSNR 31.26 vs 31.21).
- **뷰어 권장 범위:** kernel_size 3~9, 기본값 5 (아래 "뷰어 적용 제안").

## 1. 알고리즘 설명

| 항목 | 내용 |
|---|---|
| 입력 | `(H, W) uint8` grayscale, `kernel_size`(양의 홀수), `sigma`(≥ 0, 0이면 kernel_size로 자동) |
| 출력 | 같은 크기 `uint8` 새 배열 (입력은 수정하지 않음) |
| 원리 | 각 픽셀을 주변 k×k 픽셀의 **가중 평균**으로 바꾼다. 가중치는 중심에서 멀수록 작아지는 Gaussian(종 모양) 분포이며, 폭은 sigma가 정한다. 무작위로 흔들리는 잡음은 평균을 내면 상쇄되지만, 경계처럼 실제로 밝기가 바뀌는 부분도 같이 평균되어 흐려진다. |
| 라이브러리 | OpenCV `cv2.GaussianBlur(gray, (k, k), sigmaX=σ, sigmaY=σ)`, 가장자리는 기본값 `BORDER_REFLECT_101` |
| 선택 이유 | 영상 전체에 고르게 섞인 잡음(센서 잡음)을 줄이는 가장 기본적인 선형 필터라서. 결과를 해석하기 쉽고, 비선형인 Median(D)과 비교하기 좋다. |
| 핵심 코드 | `src/processing/gaussian.py` — `apply_gaussian()`(검증 후 `cv2.GaussianBlur`), `effective_sigma()`(sigma=0일 때 실제 sigma 계산), 테스트 `tests/test_gaussian.py` |

sigma=0일 때 OpenCV가 쓰는 값은 `0.3 × ((k − 1) × 0.5 − 1) + 0.8`이다: k=3 → 0.8, k=5 → 1.1, k=9 → 1.7, k=15 → 2.6.

## 2. 실험 설정

| 항목 | 내용 |
|---|---|
| 원본 | LIDC-IDRI-0002 정면 흉부 X-ray (2007×1721, 14-bit DICOM → `to_gray`로 8-bit 변환) |
| 조건 (같은 원본에서 생성) | ① 원본 / ② Gaussian 잡음 σ=15 / ③ 소금·후추 4% / ④ 밝기 ×0.5 + Gaussian 잡음 σ=10 (저선량 모사) |
| 파라미터 1: kernel_size | 3, 5, 9, 15 (sigma=0, 자동) |
| 파라미터 2: sigma | k=15에서 σ = 1, 3, 5 |
| 참고 비교 | Median 3 (`cv2.medianBlur`). Median은 D 담당이라 결론은 D 실험에 맡기고, 여기서는 Gaussian의 한계를 보이는 기준으로만 쓴다 |
| 반복 | 잡음 조건 ②~④는 seed 0~4로 5회 반복. 결과는 평균 (PSNR 표준편차 최대 0.017 dB로 매우 작음: 영상이 커서 잡음의 무작위성이 평균에 거의 영향을 주지 않음) |
| 일반화 확인 | LIDC DX 23장(10케이스) 전부에 조건 ②(seed 0)를 적용해 kernel별 PSNR 향상 비교. 대표 영상 1장만 보고 결론 내리지 않기 위함 |

**ROI** (원본 좌표, `{x, y, width, height}`, 반열림 구간):

| 이름 | 좌표·크기 | 위치 | 보려는 것 |
|---|---|---|---|
| flat | x=550, y=50, 150×150 | 목 연부조직 (밝기 고름) | 잡음이 얼마나 줄었나 |
| lung | x=300, y=900, 200×200 | 우폐야 혈관 | 미세 구조가 얼마나 남았나 |
| edge | x=300, y=1350, 200×200 | 우측 횡격막 경계 | 큰 경계가 얼마나 흐려졌나 |

**지표**

- **PSNR (dB):** 잡음을 넣기 전 영상(기준)과 얼마나 가까운가. 클수록 가깝다.
- **선명도 (512 기준):** `check_quality`와 같은 방식(#28)의 Laplacian 분산. 65 미만이면 흐림 의심.
- **flat std:** 균일 영역의 표준편차. 잡음이 줄면 작아진다.
- **오차:** ROI 안에서 기준 영상과의 평균 절대 차이.
- **경계 유지율:** ROI 안 Sobel 경계 세기 ÷ 기준 영상의 경계 세기. 1보다 작으면 경계가 약해졌다는 뜻이다. **잡음 조건(②~④)에서는 잡음도 경계로 잡혀 1보다 커질 수 있으므로**, 순수한 세부 손실은 ① 원본 표로 판단한다.
- **ROI 통계:** 평균·분산·최소·최대·256-bin 히스토그램. 계약 §4 `get_roi_stats`와 같은 정의(모집단 분산)로 계산했다.

**재현 방법:** 저장소 루트에서 `python docs/experiments/gaussian_experiment.py` (`dicom_data/`에 LIDC 필요). 결과 `result.json`과 그림이 `data/experiments/gaussian/`에 저장된다. 설정은 스크립트 맨 위 `CONFIG`에 있다. 실행 환경: Python 3.11.0, numpy 1.26.4, OpenCV 4.9.0, macOS.

## 4. 해석

**효과가 있었던 조건**
- 영상 전체에 고르게 섞인 잡음(②, ④). 평균을 내면 무작위 잡음이 상쇄된다. ②에서 flat std는 20.3 → 13.6, PSNR은 +6.5 dB였다.
- 어둡고 잡음이 많은 영상(④)일수록 큰 kernel이 유리했다(최고 k=9, +8.5 dB). 신호(대비)가 작아 잡음의 비중이 크기 때문이다.

**정보가 손실되거나 효과가 부족했던 조건**
- **세부 손실:** ① 원본에서 경계 유지율이 k=3 0.76 → k=15 0.39로 계속 떨어진다. 잡음이 없는 영상에 적용하면 얻는 것 없이 세부만 잃는다.
- **과도한 평활화:** ②에서 PSNR은 k=5 근처가 최고이고, 그 뒤로는 잡음 제거보다 세부 손실이 커져 다시 떨어진다. k=15 이상, 또는 σ ≥ 3이면 `check_quality`가 흐림으로 판정할 수준이다.
- **소금·후추 잡음(③):** Gaussian은 튀는 점을 주변으로 번지게 할 뿐 없애지 못한다. k=3·5에서는 점이 흐린 얼룩으로 남는다(`compare_lung.png` 3행). 점을 충분히 지울 만큼 kernel을 키우면(k=15) 경계 유지율이 0.42까지 떨어진다. 같은 조건에서 Median 3은 PSNR 33.2 dB로 더 높고 경계도 0.69 유지했다. **점 잡음에는 Median이 맞다.**
- **역할 구분:** ② 고른 잡음에서는 Gaussian(k=5, 31.2 dB)이 Median 3(29.8 dB)보다 나았다. 잡음 종류에 따라 맞는 필터가 다르다는 근거다.

**적용 한계**
- 잡음과 경계를 구분하지 않는 선형 필터다. 경계를 지키며 잡음을 줄이려면 Bilateral 같은 다른 방법이 필요하다(이번 범위 밖).
- 최적 kernel은 영상마다 다르다(3.3절). 고정값 하나로 모든 영상을 처리할 수 없으므로, 뷰어에서 사용자가 조절하게 둔다.

## 5. 뷰어 적용 제안 (B에게)

- kernel_size 슬라이더: **3~9 (홀수), 기본값 5.** 15는 강한 잡음에만 의미가 있고, 원본에 쓰면 흐림 의심 수준이 된다. 필요하면 15까지 열어 두되 경고 문구를 붙이는 방안도 있다.
- sigma는 기본 0(자동)을 권장한다. sigma를 따로 노출한다면, kernel이 커도 sigma가 작으면 거의 흐려지지 않는다는 안내가 필요하다(k=15·σ=1 ≈ k=5).
- 처리 이력에는 `effective_sigma(k, σ)`로 실제 적용 sigma를 함께 남기면 보고서 비교가 쉽다.

## 7. 한계

- **기준 영상은 진짜 깨끗한 영상이 아니다.** 원본 자체에 필름 잡음이 있으므로, PSNR·오차는 "잡음을 넣기 전 영상에 얼마나 가까운가"를 잰 값이다. 원래 있던 잡음을 지운 것도 오차로 계산된다.
- 잡음은 인위적으로 만들었다(Gaussian, 소금·후추, 밝기 배율). 실제 저선량 촬영의 잡음(신호에 따라 세기가 달라지는 잡음)과는 다르다.
- 대표 영상 1장에 ROI 3개를 손으로 정했다. 일반화는 23장 PSNR로만 확인했고 ROI 분석은 1장뿐이다.
- 경계 유지율은 잡음이 있으면 부풀려진다. 그래서 세부 손실 판단은 ① 원본 표를 기준으로 했다.
- 영상의 화질을 사람이 본 평가(관찰자 실험)는 하지 않았다.
